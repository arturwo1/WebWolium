This repository contains the source code for the official **Wolium™ website**.

The website serves as the central hub for the Wolium ecosystem and provides
information about the Wolium Discord bot, legal documents, and user dashboard
features.

Official website:  
https://wolium.netlify.app

---

## About Wolium™

**Wolium** is a Discord bot focused on:

- global economy systems
- activity tracking
- moderation tools
- optional AI features

The Wolium website acts as the public entry point for the project and will
gradually expand with additional systems and tools.

---

## Current Features

### 🏠 Landing Page

The main page introduces the Wolium bot and provides quick access to:

- bot description
- invite link
- support server
- official information

---

### 👤 User Dashboard

Users can log in using **Discord OAuth** and access their personal dashboard.

Current dashboard features include:

- Message activity statistics  
- Voice activity statistics  
- Activity participation statistics  

Each activity category includes:

- total values
- visual graphs

Additional data displayed:

- Experience (XP)
- Level progression
- Progress bar
- Economy statistics:
  - total balance
  - wallet balance
  - bank balance

Dashboard route:

/profile/

---

## Legal Documents

The website hosts official Wolium legal documents:
