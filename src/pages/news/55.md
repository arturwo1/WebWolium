## Dashboard Polish Update

This update focuses on improving the overall dashboard experience. Navigation is cleaner, leaderboards are easier to read, and multiple translation inconsistencies have been corrected across the site.

### New Features
- **Unread News Counter:**  
  The sidebar now shows how many news posts you haven't viewed yet. Opening the news page automatically clears the badge.

- **Improved Leaderboard Summary:**  
  Leaderboards now provide clearer information at a glance:
  - total tracked users or servers
  - currently selected metric
  - combined metric totals

### Improved
- **Cleaner Navigation Experience:**  
  Sidebar interactions and drawer behavior were improved for smoother navigation, especially on mobile devices.

- **Better Leaderboard Terminology:**  
  Several labels and metric names were adjusted to improve readability and consistency across the dashboard.

- **UI Polish Across Multiple Pages:**  
  Improved spacing, alignment, loading states, pagination behavior, and responsive layouts throughout the site.

### Localization Updates
Large translation improvements were made for:
- English
- Russian
- Ukrainian
- Lithuanian
- Spanish

This includes:
- clearer wording
- improved consistency
- cleaner leaderboard labels
- better voice/activity terminology

### Fixed
- **Leaderboard Totals:**  
  Fixed incorrect total counts shown on some leaderboard pages.

- **News Badge Persistence:**  
  Fixed cases where viewed news entries were not properly remembered between sessions.

- **Minor Visual Inconsistencies:**  
  Fixed several small UI inconsistencies across charts, profile pages, and navigation components.
