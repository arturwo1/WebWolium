## New Bunker Trait & Faster Loading

A new character trait for Bunker, plus a round of improvements that make the website load faster and feel smoother.

### Added

- **Sexual Orientation Trait:**  
  Bunker character cards now include a sexual orientation, shown next to the gender trait. Each player gets a randomly generated orientation, and the new trait is fully translated into all supported languages.

### Improved

- **Faster Loading:**  
  Pages now load only the code they actually need, and the Discord integration starts only when it's required. The website opens faster, especially on slower connections.

- **Loading Placeholders:**  
  Account settings and server statistics now show skeleton placeholders while data loads, instead of empty space or content jumping around.

- **Smoother Animations:**  
  The void animation now runs at the same speed on any screen, regardless of refresh rate, and no longer stutters on slower devices.
