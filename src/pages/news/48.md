## Commands chart, user search, and loading improvements

A new update adds the ability to look up any user's profile, track command usage on charts, and improves how pages load.

### Added
- **User search:** A search bar is now available in the top navigation — enter a nickname or Discord user ID and press Enter to open that user's profile
- **Commands chart:** A new "Commands" tab is available in the chart modal — see how many slash commands a user has used over time, filter by server, channel, or command name
- **Commands stat:** The profile page now shows total command count alongside messages, voice, and activity stats
- **Offline page:** If you lose connection and a page isn't cached, you'll now see a proper offline screen instead of a browser error

### Improved
- Profile and stats sections now show a loading animation while data is being fetched, instead of displaying placeholder "???" values instantly
- Chart modal shows a loading state while new data is loading
