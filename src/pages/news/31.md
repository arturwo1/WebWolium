## Profile loading and asset handling improvements

The website received a technical update focused on loading speed, assets, and preview quality.

### Improved
- Profile loading now uses local storage caching
- Optimized image handling was added
- Message previews received better Discord timestamp formatting and styling
- Service worker caching and asset handling were reworked

### Result
- Faster profile loading in repeat sessions
- Cleaner preview output
- More stable asset delivery
