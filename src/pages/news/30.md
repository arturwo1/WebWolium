## Privacy update and website launch

### Website
- The website was migrated to **https://wolium.netlify.app/**

### Security and data handling
- Command logic was simplified
- Data handling methods were secured

### Privacy system
- Added **/privacy** and **/delete_data**
- Added configurable privacy flags
- User consent is now required for data collection
- Message logging now respects privacy settings

### Other changes
- Added a **News** tab in **/settings**
- Added channel and news type selection
- The bot now sends messages to the main chat only when necessary
