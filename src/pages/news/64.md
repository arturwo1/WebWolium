## Language Selector Fix & Session Stability

A smaller update to the website focused on fixing the language selector, improving login stability, and helping search engines properly index the home page.

### Fixed

- **Language Selector:**  
  Fixed the language selector on the account settings demo, which was showing an empty list of languages instead of the available options.

### Improved

- **Search Engine Indexing:**  
  Home page translations are now rendered on the server, so search engines and other crawlers can properly read the localized content instead of only seeing it after the page loads in your browser.

- **Login Stability:**  
  Fixed a rare issue where logging in around the same time as another session could interrupt the Discord authentication process, making logins more reliable overall.

- **Demo Widgets:**  
  Expanded the sample data shown in the interactive demos with more variety across names, servers, channels, and messages, and added an offline status option.
