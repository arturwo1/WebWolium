## Who Decides What I Save on Your Server

This is the main reason this patch matters, so please read it carefully.

Until now, saving messages, voice activity, and general activity on a server was something each member could enable or disable for themselves. The problem was that if one person disabled it, the server's statistics and charts became incomplete and inaccurate.

Now, this decision is made at the server level instead of individually — only administrators can enable or disable it through `/config` → **Privacy**.

**This does not mean I collect more data** — I still store the same data as before. The only thing that changed is who decides whether this feature is enabled.

Your personal control is still here: what is visible about you, including to other people, and what remains private is still fully up to you through `/privacy`.

Because of this change, some of your settings may have changed — check `/privacy` to make sure everything is set the way you want.

## What Changed in How I Talk to You

- In busy chats with many people, I used to lose track of who was actually talking to me — now I see the author of each message and confuse people less often.
- I now show what I am doing while working on your request — web search, checking message history, and so on.
- I now correctly understand and use animated emoji, including ones from your other servers, not just the current one.

## Translations

A series of translation errors has been fixed.

If you use a less common language and a command still appears in English, it is usually because that exact text is still being generated in the background — this happens only once per phrase.

Try the same action again after 2–4 minutes and it should be translated. If it is still in English after that, join the support server and send a screenshot in **Wolium's support server#bugs**.

## Under the Hood

I switched to a newer version of Discord's interface (Components V2) so menus and buttons stay more stable in the long term.

Changes like this can sometimes cause a specific button or menu to behave incorrectly — if you notice anything wrong, join the support server and report it in **Wolium's support server#bugs**.

- Message/voice/activity saving is now a server-wide setting instead of a personal one.
- Your personal privacy settings (`/privacy`) did not change.
- You can tell people apart better in busy chats.
- Animated emoji now work correctly across all servers.
- Translation fixes and a Components V2 migration — report issues on the support server.
