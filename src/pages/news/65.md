## Wolium™ v3.4.0 — Account Requirement for Chat & Voice Chart Upgrades

Wolium™ v3.4.0 focuses on chat reliability, voice chart features, and an internal data layer rewrite.

This update introduces a linked account requirement for chatting with Wolium™, improves chat context and tool usage, adds an **Only moves** filter and richer previews to voice charts, fixes `/translate`, and replaces the way data is written so saves are now instant.

---

## 🤖 Chat Update

### Linked Account Required

Chatting with Wolium™ now requires a linked account.

- **What changed:**  
  To chat with Wolium™, you now need to sign in on the website through Discord once.

- **How long it takes:**  
  About a minute.

- **If you don't have one yet:**  
  If you try to chat without a linked account, Wolium™ will guide you through linking.

- **Everything else:**  
  The rest of Wolium™ works exactly as before — only chatting is affected.

---

### Chat Improvements

Chat quality and reliability were improved in this update.

- **Tool usage returned:**  
  Wolium™ can call tools again — web search, message history, profiles, and reactions.

- **Better context:**  
  Wolium™ holds context much better across a conversation.

- **Known limitation:**  
  On the new API, Wolium™ is less stable on very long dialogues and may break or respond worse when asked to search the web or read channel history. This is being worked on.

---

## 🌐 Website Update

### Voice Chart Updates

Voice charts received new filtering and richer previews.

- **Only moves filter:**  
  Voice charts now support an **Only moves** filter for sessions where the user mostly hopped between channels.

- **Richer previews:**  
  Voice previews now show channel transitions, jump counts, and channel counts.

- **Channel links:**  
  Individual voice events now link to the corresponding Discord channel.

- **Localization:**  
  New chart labels were localized across supported languages.

---

### Commands & Interface

A few website and command-side details were cleaned up.

- **`/translate` fixed:**  
  The command could previously return the wrong cached translation. It now translates the message you actually gave it.

- **Voice stats interface:**  
  The voice stats interface on the site was updated to match the new chart features.

---

## ⚙️ Under the Hood

A significant internal change was made to how Wolium™ stores data.

- **New data layer:**  
  Wolium™ now writes through a Redis-backed write-behind layer in front of PostgreSQL.

- **Instant saves:**  
  Saves are now instant — previously they could sit in a queue for up to a minute.

- **Faster repeat requests:**  
  Repeat requests to Wolium™ now land in **0–6s** instead of **3–14s**.

- **Snappier commands:**  
  Profiles, stats, and economy commands should feel snappier overall.

- **Future foundation:**  
  This change unlocks complex live interactions between dozens of users later on.

- **Small sync delay:**  
  There is now a small delay between Wolium™ and the website. Most of the time you won't notice it, and changes you make on the site still reach Wolium™ almost instantly.
