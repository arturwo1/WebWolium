## Server Dashboard Beta

This update introduces the first beta version of the server dashboard. You can now browse your Discord servers, filter them by access level, and open a dedicated dashboard page for each server.

### New Features

- **Discord Servers List:**  
  Added a new servers page where you can see your Discord servers in one place.

- **Server Access Filters:**  
  Servers can now be filtered by access level: full access, management, moderation, or member access.

- **Server Search:**  
  Added search to quickly find a specific server.

- **Dedicated Server Pages:**  
  Each server now has its own dashboard page with server information, XP progress, balance stats, and analytics.

- **Server Analytics:**  
  Server dashboards now include analytics for messages, voice time, activity time, and member count.

- **Member Count Tracking:**  
  Added a new member chart that shows server member count changes over time.

- **Channel and Role Filters:**  
  Server charts now support filtering by channels and roles where available.

- **Bot Missing Screen:**  
  If Wolium is not on the selected server, the dashboard now shows a clear message with an invite button.

### Improved

- **More Stable Discord Login:**  
  Discord access is now refreshed more reliably, so server data should keep loading without requiring frequent re-login.

- **Clearer Server Navigation:**  
  The dashboard now separates the server list and individual server pages.

- **Better Chart Preview Cards:**  
  Server chart previews now show clearer information for messages, voice activity, activities, and member count.

- **Updated Sidebar:**  
  The Servers page is now marked as beta while server dashboard features are still being expanded.

- **Updated Interface Text:**  
  Added and updated translations for the new server dashboard, server filters, chart labels, and member analytics.

### Fixed

- **Expired Discord Access:**  
  Fixed cases where Discord server data could stop loading after the Discord access token expired.

- **Chart Filter Switching:**  
  Improved how chart filters update when switching between message, voice, activity, and member charts.

- **Server Dashboard Loading:**  
  Improved loading behavior for server pages and saved server data.

### Notes

This is the first beta version of the server dashboard. More server settings and configuration tools will be added in future updates.
