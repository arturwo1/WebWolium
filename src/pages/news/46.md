## News page and profile improvements

A larger website update was released for news, profile charts, previews, and mobile interaction.

### Added
- A public **News** page on the website
- Separate pages for each news post
- News filters by:
  - source
  - priority
  - type
  - time
- Pagination and page jump for news
- New profile chart tabs:
  - **Messages**
  - **Voice**
  - **Activities**
- Message filters by:
  - server
  - channel
  - message text
- Voice filters by:
  - server
  - channel
  - min duration
  - max duration
- Activity filters by:
  - name
  - status
  - duration
  - track
  - album
  - artist
- Rich activity cards with:
  - status
  - device
  - Spotify/media details
  - links
- Code highlighting on the website

### Improved
- Message previews can now show images from messages
- Profile charts work better on mobile devices
- Sidebar can now be opened with a swipe on mobile
- News labels, statuses, and interface text received localization updates
- **News** now appears before **Settings** in the sidebar
- **News** now uses its own sidebar icon
- Profile chart tabs now handle long labels better
- Long tab names are truncated instead of overflowing
- The tabs area becomes scrollable when there is not enough space

### Changed
- Profile and chart commands in the bot now also provide a website link for a more detailed view
