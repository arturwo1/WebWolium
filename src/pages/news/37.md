## Wolium v2.2.0

### Website
- Added a new homepage
- Improved the website and dashboard UI
- Improved localization

### Privacy and security
- Personal messages are no longer stored
- Added protection against linking multiple Discord accounts
- Blocked users can no longer access web features

### Leaderboards
- Usernames are now shown instead of mentions
- Improved display for users outside the server
- Improved server ranking display

### Translations
- Added new translations for commands and settings
- Improved language name display

### Stability
- Improved freeze detection
- Improved background query stability
- Fixed minor issues in profiles, graphs, and the website

### Notes
- The bot may use the default channel if no channel is configured
- Admins should configure channels through **/settings**

### Summary
- Website update
- DMs are no longer saved
- Leaderboards improved
- New translations added
