## Wolium™ v3.3.0 — New Home Page, AI Vision & SSTV

This update brings a major redesign to the website's home page, adds image support to the AI assistant, introduces a new SSTV encoding command, and gives administrators more control over moderation and privacy.

---

## 🌐 Website Update

### New Features

- **Wolium / WebWolium Tabs:**  
  The home page is now split into two tabs — Wolium, covering the Discord bot, and WebWolium, covering the site — each broken down into Admin and User views.

- **Interactive Live Demos:**  
  The WebWolium tab now includes working demo versions of the profile, servers list, server analytics, chart, leaderboard, and account settings pages, filled with sample data so they can be explored before logging in.

- **Sticky Tabs Bar:**  
  A tabs bar now stays visible and follows along as you scroll past the main Wolium/WebWolium section.

- **Faster Page Loads:**  
  API responses are now cached, so pages such as server analytics and leaderboards load faster on repeat visits.

### Improved

- **Rewritten Page Copy:**  
  Feature and command descriptions across the home page were rewritten to be clearer, with screenshots and gifs attached to the specific feature they describe.

- **New Content Layout:**  
  Features are now presented as cards, carousels, and accordions with tooltips and "read more" details instead of one long feature list.

- **Visual Refresh:**  
  Added a subtle animated background, along with hover and scroll animations across the home page.

- **Clearer Icons:**  
  Menu and tooltip info icons across the dashboard now use SVG icons instead of text or emoji characters.

- **Updated Translations:**  
  Added and updated translations for the new home page content and settings in every supported language.

---

## 🤖 Discord Bot Update

### New Features

- **AI Image Support:**  
  The AI assistant can now see and respond to up to 3 image attachments per message, instead of only reading their filenames.

- **AI Thinking Status:**  
  If the AI takes a few seconds to respond, a status message now appears and updates live with what it's currently doing.

- **SSTV Encoding:**  
  A new command converts any image into an SSTV (Slow-Scan Television) audio signal, with several modes to choose from. The result can be sent as a file, a voice message, or played directly in a voice channel.

- **Channel Whitelist & Blacklist:**  
  Auto-moderation and the AI assistant can now each be restricted to specific channels, configured separately through `/settings`.

- **Server-Level Privacy Settings:**  
  Message, voice, and activity saving preferences are now controlled at the server level instead of per-member, with changes logged to your mod-log channel.

### Improved

- **`/purge` Rewritten:**  
  Deleting a large number of messages now works reliably for any amount requested, and two purges can no longer run in the same channel at once.

- **Translation Reliability:**  
  Fixed cases where placeholders like usernames or numbers could get broken during machine translation.

### Fixed

- **`/work` Cooldowns:**  
  Cooldown timers now show as live countdown timestamps instead of static text.

- **`/holidays`:**  
  Fixed the command failing to load correctly.

- **Profile Rank Badge:**  
  Fixed the rank badge overlapping the avatar on `/profile`.

- **Leaderboard Entries:**  
  Fixed leaderboard entries for uncached users or servers showing a broken mention instead of their real name.

- **Animated Emoji:**  
  Fixed animated emoji not being recognized correctly by the AI.

---

## ⚖️ Legal

- **Privacy Policy:** clarified that data deletion is now handled per-feature through the Bot or website settings rather than a single command.
- **Terms of Service:** disclosed Stripe as a payment provider and expanded the liability and intellectual property sections.
