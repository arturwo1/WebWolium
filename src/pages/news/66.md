## Wolium™ v3.5.0 — Bunker Game, Discord Activity & Smarter Auto Moderation

This update adds a new game to the bot, shows its history on the website, lets you open the website inside Discord, and makes auto moderation smarter.

---

## 🏚️ Bunker

### New Features

- **Bunker game:**  
  A catastrophe hits, and the bunker has room for only some of you. Start a game with `/bunker`, get a character card, reveal traits round by round, argue in chat and vote who gets thrown out.

- **Bots as players:**  
  If there aren't enough players, I fill the empty seats myself.

- **Private threads:**  
  Every player gets a private thread with their card.

- **AI story:**  
  When the game ends, I write a story about how it went.

- **Saved games:**  
  Finished games are saved, so you can look back at them later.

---

## 🌐 Website Update

### New Features

- **Bunker on your profile:**  
  The profile now has a Bunker button with every game you played, and the number of games is shown in your stats.

- **Game viewer:**  
  Each game opens with four tabs: my story, the players, a round-by-round replay (reveals, votes, chat) and the match info with the catastrophe, settings and bunker equipment.

- **Bunker demo:**  
  The homepage has an interactive Bunker demo with randomized fake games, so you can try it without logging in.

- **Shareable chart links:**  
  Chart filters, presets and custom date ranges are now saved in the page link, so you can share exactly what you see. Opened windows and tabs are restored from the link after a reload.

### Improved

- **Real names in mentions:**  
  Mentions of users, channels and roles on the website now show real names and link to Discord.

- **Descriptions:**  
  Added explanations for phobias and bunker equipment.

- **Login redirect:**  
  After logging in, you return to the page you were on.

- **Keyboard navigation:**  
  Dropdown menus can now be fully used with the keyboard.

- **Translations:**  
  All new Bunker texts are translated into English, Spanish, Lithuanian, Russian and Ukrainian.

---

## 🎮 Discord Activity

- **Website inside Discord:**  
  You can now open the website as an Activity right inside Discord and log in there in one click.

- **Launch command:**  
  I now have a launch command for it.

- **Deep links:**  
  Launching the Activity from the bot can take you straight to the right page, such as Bunker.

---

## 🛡️ Auto Moderation

- **Per-channel context:**  
  I now follow each channel's conversation separately, so context no longer leaks between channels.

- **Deleting previous messages:**  
  I can delete the offender's previous messages too, not only the last one.

- **Missing permissions:**  
  If I'm missing permissions, I tell you once an hour instead of silently failing.

- **Bots ignored:**  
  Messages from other bots are no longer checked by auto moderation or answered by the AI.

---

## 🌍 Translations & Commands

- **Localized command names:**  
  Command names are now localized for Spanish, Lithuanian, Russian and Ukrainian.

- **`/translate`:**  
  I skip text that's already in your language, and long results no longer break.

- **Outdated translations:**  
  Changed texts are now retranslated instead of staying outdated in other languages.

---

## 🛠️ Small Fixes

- **Durations:**  
  Durations no longer show things like "2h 0s".

- **Time inputs:**  
  A time with an unknown unit is now treated as seconds instead of failing.

- **`/text`:**  
  Removed the old penalty for using @here and @everyone.
