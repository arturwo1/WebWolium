## Wolium v2.0.0

### Highlights
- Official website launched: **https://wolium.netlify.app/**
- Added a profile page with stats and interactive activity graphs
- Added graph zoom and quick navigation to Discord

### Privacy
- Added full privacy control through **/privacy**
- Data collection now depends on user consent
- Added clearer explanations about stored data and usage

### Open source
- Source code is available at:
  - **https://github.com/arturwo1/Wolium**

### Changes
- Improved performance and stability
- Simplified and optimized the codebase
- Added **/privacy** and **/delete_data**
- Moved **/insert_date** to the privacy category

### Notes
- The bot now works **24/7** again
- Updates resumed after the inactivity period
- Admins can configure channels through **/settings**
