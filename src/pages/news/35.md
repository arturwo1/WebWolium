## Consent settings, analytics, and icon system update

The website now includes analytics and ad support with privacy-safe default behavior.

### Added
- Google Analytics
- AdSense support
- Default-denied consent mode

### Changed
- The UI icon system was switched to SVG icons

### What this means
Analytics and ads were added, but consent is denied by default until the user allows it through the website controls.
