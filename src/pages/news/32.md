## Localization and multilingual UI improvements

Localization support on the website was expanded and cleaned up.

### Added and improved
- UI template localization
- Localized text for profile and charts
- Language selector improvements in settings
- Dynamic language loading
- Native language names
- Updated Ukrainian localization entries

### Fixed
- Active chart type clicks no longer reset zoom

This update made the website more consistent for multilingual use and improved chart behavior.
