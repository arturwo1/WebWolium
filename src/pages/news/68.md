## Modular Server Settings & Bunker Controls

A complete overhaul of the server management dashboard: a modular tile-based layout, instant search, mobile-first controls, and dedicated configuration for Bunker games.

### Added

- **Bunker Game Configuration:**  
  Administrators can now fully customize Bunker games directly from the dashboard. Set launch permissions (admins, specific roles, or everyone), assign custom Discord categories, adjust player limits and bunker capacity, and fine-tune phase durations with live round-length estimates.

- **Quick Search Palette (Ctrl + K):**  
  Find any server setting in seconds. Pressing `Ctrl + K` (or using the search bar) opens an instant search modal that jumps directly to the targeted option and highlights it on the page.

- **Drag-and-Drop Word Lists:**  
  Word chain settings now use interactive chips that can be reordered via drag-and-drop on both desktop and touchscreens. New words can be quickly appended using commas or the Enter key.

- **Floating Save Bar & Change Diff:**  
  Unsaved edits now trigger a non-intrusive floating action bar. Before saving, admins can open the built-in diff viewer to inspect an exact "before → after" summary of modified values or reset changes with one click.

### Improved

- **Tile-Based Navigation:**  
  The settings page has been redesigned to eliminate endless scrolling. Categories are presented as clean tiles with real-time status summaries, breadcrumbs, and focused sub-screens.

- **Searchable Dropdowns:**  
  All dropdown selectors have been upgraded to custom searchable menus with built-in quick-clear (`×`) buttons, auto-positioning, and isolated stacking contexts that never get cut off by surrounding cards.

- **Mobile & Touch Experience:**  
  Select menus on mobile screens now present as native-like centered sheets, and input fields properly adjust to virtual on-screen keyboards without layout jumps.

### Fixed

- **Long Server & Profile Names:**  
  Server titles and user profile names no longer overflow or break page grid containers, smoothly clamping to two lines with proper ellipsis.
