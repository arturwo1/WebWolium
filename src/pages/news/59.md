## Server Settings

This update introduces the first version of server settings, allowing administrators to configure many bot features directly from the dashboard.

### New Features

- **Server Settings Panel:**  
  Added a new settings page for Discord servers.

- **Automatic Moderation Settings:**  
  Configure moderation, moderation mode, moderation rules, and log channels.

- **AI Assistant Settings:**  
  Configure AI features and automatic message expiration for AI responses.

- **Word Game Settings:**  
  Configure the word game channel, used words history, and filter mode.

- **Counting Game Settings:**  
  Select the channel used for the counting game.

- **Notification Settings:**  
  Configure channels for news, important announcements, and critical alerts.

- **Message TTL:**  
  Configure automatic message deletion for individual channels using flexible time formats.

### Improved

- **Servers Are Now Stable:**  
  The Servers section is no longer in beta and is now part of the standard dashboard.

- **More Secure Discord Authentication:**  
  Discord access tokens are now validated more securely before accessing protected server features.

- **Automatic Token Refresh:**  
  Discord authentication is refreshed more reliably without requiring users to sign in again as often.

- **Permission Verification:**  
  Server settings can now only be accessed and modified by server administrators.

- **Improved Server Navigation:**  
  Server pages now recognize administrator access directly from the server list.

- **Cleaner Interface:**  
  Multiple server pages and preview components have been refactored for improved consistency and maintainability.

- **Updated Translations:**  
  Added and updated translations for all new server settings in every supported language.

- **Dependency Updates:**  
  Updated project dependencies and added the Sharp image processing library.

### Fixed

- **Authentication Handling:**  
  Fixed several cases where expired Discord authentication could prevent server pages from loading correctly.

- **Configuration Validation:**  
  Improved validation for moderation settings, word lists, filters, and TTL values before saving.

- **Settings Stability:**  
  Improved reliability when loading and saving server configuration.
