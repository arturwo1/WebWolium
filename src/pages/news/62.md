## Redesigned Home Page

The home page has been completely rebuilt to make it easier to see what Wolium and WebWolium can actually do.

### New Features

- **Wolium / WebWolium Tabs:**
  The home page is now split into two tabs — Wolium (the Discord bot) and WebWolium (the site) — each with separate Admin and User views.

- **Interactive Live Demos:**
  The WebWolium tab now embeds real, interactive previews of the profile, servers list, server analytics, charts, leaderboard, and account settings pages, filled with sample data you can actually click through.

- **Rewritten Page Copy:**
  Hero text, feature descriptions, and command documentation have been rewritten in a more direct, first-person voice, with screenshots and gifs attached to the specific command or feature they illustrate.

- **New Content Layout:**
  Features are now presented as cards, carousels, and accordions with tooltips, "read more" modals, and a sticky tab bar that follows you as you scroll.

- **Animated Background:**
  Added a subtle animated particle background, with cards that gently float and fade in as you scroll.

## Server Settings

- **Channel Whitelist & Blacklist:**
  You can now restrict the AI bot and auto moderation to specific channels using new whitelist and blacklist selectors in server settings.

- **Privacy Settings Moved to Server Config:**
  Message, voice, and activity saving preferences have moved from personal user settings into server settings, so they're now controlled per-server instead of per-user.

## Performance

- **Faster Page Loads:**
  API responses are now cached, so pages such as server analytics and leaderboards load faster on repeat visits.

## Legal

- **Updated Privacy Policy:**
  Clarified that data deletion is handled per-feature through the Bot or website settings rather than a single command, and updated age-compliance wording to reference Discord's Terms of Service.

- **Updated Terms of Service:**
  Added Discord ToS age-compliance requirements, disclosed Stripe as a payment provider, and expanded the liability and intellectual property sections.

### Improved

- **Icons:**
  Menu and tooltip info icons across the dashboard now use crisper SVG icons instead of text/emoji characters.

- **Translations:**
  All new tabs, settings, and privacy sections are fully translated across English, Spanish, Lithuanian, Russian, and Ukrainian.
