## Chart Comparison Tools

Charts across the dashboard now support new analysis options, making it easier to spot trends and changes over time.

### New Features

- **Compare with Previous Period:**  
  Overlay the previous time period on any chart to instantly see how activity has changed.

- **Show Changes:**  
  Switch a chart to display the change between each data point instead of raw totals.

- **Average Line:**  
  Add a dashed average line to any chart to quickly see whether a given point is above or below the norm.

- **AI Conversation Auto-Delete:**  
  A new server setting lets administrators automatically delete both a user's message and the AI's reply after a set time.

### Improved

- **Smarter Chart Coloring:**  
  Chart lines now shift color as values move further away from the average, making spikes and drops easier to spot at a glance.

- **Better Dropdown Menus:**  
  Dropdown menus (including the account menu and new chart options menu) now position themselves correctly regardless of where they appear on the page, and no longer get cut off near screen edges.

- **Cleaner Server Settings Layout:**  
  Setting labels and their info tooltips are now displayed more consistently across the settings panel.

- **Updated Translations:**  
  Added translations for all new chart options and the AI conversation auto-delete setting in every supported language.

- **Dependency Updates:**  
  Updated project dependencies for improved stability and performance.

### Fixed

- **Chart Tooltips:**  
  Fixed tooltip positioning and content when hovering over comparison, average, or change data points.
