## Profile Update

This update improves profile pages, charts, public stats, and account sessions. The dashboard should now feel more stable, load data more reliably, and keep users signed in for longer.

### New Features

- **Longer Lasting Sessions:**  
  You should no longer be logged out just because your session token expired after some time. If your browser still has a valid saved session, the site will refresh it automatically.

- **Improved Profile Charts:**  
  Profile charts now support smoother interactions and better data browsing.

- **Safer Public Stats Loading:**  
  Home page stats now load in a more reliable way, helping keep public dashboard data stable even during higher traffic.

### Improved

- **Faster Profile Loading:**  
  Profile data requests are now handled more efficiently, which should make profile pages respond faster in many cases.

- **Smoother Chart Experience:**  
  Chart zooming, panning, previews, filters, and tooltips were improved to make profile activity easier to explore.

- **More Reliable Dashboard Data:**  
  Several data loading paths were improved to reduce failed or unnecessary requests.

- **Better Future Chart Support:**  
  The chart system was reworked so similar charts can be added to more pages in future updates.

### Fixed

- **Unexpected Logouts:**  
  Fixed an issue where users could be logged out after about an hour even if their browser still had a valid saved login.

- **Profile Chart Issues:**  
  Improved chart stability and behavior when loading, filtering, or interacting with profile data.

- **Public Stats Reliability:**  
  Improved how home page stats are loaded to make them more stable and resistant to unnecessary traffic.
