## Wolium v3.2.0 — Server Dashboard & Website Upgrade

Wolium v3.2.0 is mainly focused on improving the website.

This update adds the first beta version of the server dashboard, improves profile charts, makes dashboard sessions more reliable, adds unread news tracking, improves leaderboards, and polishes multiple parts of the interface.

The Discord bot also received smaller quality improvements, mostly around command text, translations, menus, and reliability.

---

## 🌐 Website Update

### Server Dashboard Beta

The website now has the first beta version of the new server dashboard.

- **New servers page:**  
  You can now see your Discord servers in one place.

- **Server search:**  
  Added search for quickly finding a specific server.

- **Permission filters:**  
  Servers can now be filtered by full access, management permissions, moderation permissions, or regular member access.

- **Dedicated server pages:**  
  Each server now has its own dashboard page.

- **Bot missing screen:**  
  If Wolium is not on a selected server, the dashboard now shows a clear message with an invite button.

- **Servers beta badge:**  
  The Servers section is now marked as beta while the dashboard is still being expanded.

---

### Server Analytics

Server pages now include the first version of server analytics.

- **Messages chart:**  
  View message activity across the server.

- **Voice chart:**  
  View total voice activity over time.

- **Activity chart:**  
  View activity time across server members.

- **Member count chart:**  
  Track how the server member count changes over time.

- **Channel filters:**  
  Filter supported server charts by channel.

- **Role filters:**  
  Filter supported server charts by role.

- **Clearer chart previews:**  
  Server chart previews now show clearer information for messages, voice time, activities, and member count.

---

### Profile & Chart Improvements

Profile pages and charts should now feel smoother and more stable.

- **Faster profile loading:**  
  Profile data should load more efficiently in many cases.

- **Smoother chart browsing:**  
  Chart zooming, panning, previews, filters, and tooltips were improved.

- **Better profile chart filters:**  
  Message and voice chart filters should behave more consistently.

- **More stable chart switching:**  
  Switching between chart types should now update filters more reliably.

- **Better future chart support:**  
  The chart system was improved so more chart types can be added to more pages later.

---

### Sessions & Loading

Dashboard login and loading behavior was improved.

- **Longer lasting sessions:**  
  You should no longer be logged out just because a session expired after some time.

- **More reliable Discord server loading:**  
  Server lists and server pages should load more reliably during longer sessions.

- **Cleaner expired login handling:**  
  If the dashboard can no longer use your Discord login, it now handles that state more cleanly.

- **Safer public stats loading:**  
  Home page stats now load in a more reliable way.

- **More reliable dashboard data:**  
  Several dashboard pages should now fail less often and avoid unnecessary reloads.

---

### News Tracking

News tracking was improved on the website.

- **Unread news counter:**  
  The sidebar now shows how many news posts you have not viewed yet.

- **Automatic clearing:**  
  Opening the news page clears the unread news badge.

- **Better persistence:**  
  Viewed news entries should now be remembered more reliably between sessions.

---

### Leaderboards

Leaderboards were improved and made easier to read.

- **Improved leaderboard summary:**  
  Leaderboards now show clearer overview information.

- **Total tracked users or servers:**  
  Leaderboard pages can now show how many users or servers are included.

- **Combined metric totals:**  
  Leaderboards can now show combined totals for selected metrics.

- **Better terminology:**  
  Several labels and metric names were adjusted for better readability.

- **Fixed total counts:**  
  Fixed cases where some leaderboard pages could show incorrect total counts.

---

### Dashboard Polish

Several parts of the website interface were cleaned up.

- **Cleaner navigation:**  
  Sidebar interactions and drawer behavior were improved.

- **Better mobile experience:**  
  Navigation and dashboard layouts should feel smoother on smaller screens.

- **Improved loading states:**  
  Multiple pages now show loading and saved data states more cleanly.

- **UI cleanup:**  
  Improved spacing, alignment, pagination behavior, responsive layouts, and small visual details across the dashboard.

---

### Localization Updates

Large translation improvements were made across the website.

Updated languages include:

- English
- Russian
- Ukrainian
- Lithuanian
- Spanish

This includes:

- clearer wording
- more consistent labels
- better server dashboard text
- cleaner chart labels
- improved leaderboard wording
- better voice and activity terminology

## 🤖 Discord Bot Update

The Discord side of Wolium received smaller quality improvements in this update.

### Command Text Improvements

Several Discord command descriptions and long help texts were cleaned up.

- Command descriptions are now easier to translate.
- Help text was reorganized.
- FAQ text was cleaned up.
- Holiday command text was improved.
- Link command text was improved.
- More command text can now be updated consistently across languages.

---

### Holiday Command Improvements

The holiday command was updated to use clearer holiday names and seasons.

- Holiday names should be easier to translate.
- Holiday season colors are now more consistent.
- Current holiday and all-holidays views should be cleaner.

---

### Link Command Improvements

The `/link` command was improved.

- Redirect results are now clearer.
- More website response statuses are shown properly.
- Invalid links now show clearer errors.
- Connection errors now show clearer errors.
- Timeout errors now show clearer errors.
- Too many redirects now show a clearer message.

---

### Interaction Stability

Several Discord menus and buttons were improved.

This affects parts of:

- Help menu
- Holiday pages
- Server settings
- Privacy settings
- Moderation settings
- Notification settings
- Message deletion settings
- Game channel settings

These menus should now be more stable and easier to use.

---

### Safety & Reliability

Several smaller reliability improvements were included.

- Wolium now avoids unwanted mentions in bot replies by default.
- Some member join and leave handling was made safer.
- Member count changes can now be reflected in server analytics.
- Some noisy internal Discord logging was reduced.
- Hardware monitoring was made less aggressive.

---

## 📌 Development Focus

Starting from this update, the Discord bot side of Wolium will receive updates less often and less actively for a while.

The main focus has moved to the website. Most new features will be added to the website first, and only later appear inside Discord when it makes sense.

Some advanced functionality will always stay website-only because it is much more comfortable to use there than through Discord commands.

The current plan is to keep the website as the main priority until around **January 2027**.

If the website is finished earlier, Discord bot development will return earlier. If the website needs more time, the website will stay the priority for longer.

After that, the focus will move back to new Discord bot features, fixes, and improvements for the Discord side of Wolium.
