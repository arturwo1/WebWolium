## Wolium v2.1.0

### New
- Added an auto-delete system for messages per channel
- Timers can be configured through **/settings**

### Supported time formats
- `10s`
- `5m`
- `2h`
- `1d`
- combined values such as:
  - `1h 30m`
  - `1.5h`

### Changes
- Simplified data storage logic
- Removed deprecated code
- Cleaned up the architecture

### Notes
- Features become available immediately after deployment
- News summaries are planned every **1–3 weeks**

### Summary
- Channel-based auto-delete timers
- Flexible time format
- Improved internal architecture
