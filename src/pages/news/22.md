## Command migration and new features

### Migrated commands
The following commands were moved to the new system:
- **/transaction**
- **/leaders**
- **/text**
- **/embed**
- **/delete**
- **/format_numbers**
- **/holidays**

### Notes
Development was delayed because of work on autologs.

- **2025-03-29:** message translation was added through **Apps → Translate**
