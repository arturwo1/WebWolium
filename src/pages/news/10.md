## Inflation system added

A new inflation system has been added.

Inflation now depends on:
- total user balance
- upgrades

This means economy commands are now much more affected by inflation.

### Changes
- Some commands now require bank registration:
  - **/text**
  - **/embed**
  - **/calculate**

### Planned
- Add **/roulette**

### Known issue
- **/leaders** is currently broken
