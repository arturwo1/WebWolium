## Profile update

The **profile chart** section now includes new tabs, filters, and a more detailed activity view.

### Added
- Tabs:
  - Messages
  - Voice
  - Activities
- Server and channel selection
- Voice filters:
  - Min duration
  - Max duration
- Activity filters:
  - Name
  - Status
  - Duration
  - Media info
- Detailed activity view:
  - Spotify
  - Status
  - Media details
  - Links

### Improved
- Faster and smoother switching between tabs
- Updated modal layout
- Localized activity statuses
