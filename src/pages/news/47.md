## Visual improvements and UI fixes

A minor update was released to improve navigation and fix small visual issues on the website.

### Added
- New SVG icons for left and right navigation arrows

### Improved
- **News navigation:** Pagination buttons and the "Back to news" link now use the new vector icons, replacing the previous text and fixing encoding issues with broken special characters
- **Localization:** Cleaned up text strings for the back button in English, Spanish, Lithuanian, Russian, and Ukrainian
- **Responsiveness:** Badge rows now wrap correctly (`flex-wrap`) when they do not fit the screen width

### Removed
- Text tooltips (`title` attributes) on hover for activity card images
- Legacy time parameter handling (`activity_started_at`, `activity_ended_at`) when rendering profile charts
