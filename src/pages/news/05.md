## Economy update and boosts

Boosts are now available in **/shop**.

A second way to earn boosts is planned for tomorrow:
- **10% chance** to receive a boost when leveling up

### Economy changes
- All balances were reduced by **100×** (this was **not** a reset)
- **/work** cooldown: **5h → 38m**
- **/rob** cooldown: **24h → 6h**

### Known issues
- You can rob yourself
- Errors may still trigger cooldowns
- A boost may be consumed if the shop returns an error
- The bot may occasionally skip message checks
- **/work** can rarely produce a negative reward
- Admin commands are currently broken

### Planned for tomorrow
- Fix boost loss on shop error
- Add boost drops from leveling
- Fix self-rob if there is enough time
- Continue general bug fixing

### Later
- Add **/tic-tac-toe**
