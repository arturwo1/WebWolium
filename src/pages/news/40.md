## Wolium v2.3.0

### Website
- Added a settings page
- Added cookie consent
- Updated the homepage and localization
- Added page transition animations
- Updated the logo and favicon

### Profile
- Discord status is now shown on the avatar
- Hover now shows the active device:
  - PC
  - mobile
  - browser
- Improved graph previews

### Privacy and activity
- Added more detailed privacy settings
- Split activity into categories
- Prepared a new system for tracking Discord activity

### Improvements
- Improved message and voice graphs
- Faster Discord `.zip` data import with real-time results

### Planned next
- Detailed activity graphs on the website
- Advanced message filters:
  - servers
  - channels
  - context
- Advanced voice sorting
- Extended activity filtering
- Image previews in message history

### Summary
- Website settings and cookies
- Discord status in profile
- Expanded privacy system
- More detailed analytics planned
